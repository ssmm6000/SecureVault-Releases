# المحفظة الآمنة — Secure Vault

برنامج لويندوز يحفظ **ملفاتك وحساباتك الرقمية** (اشتراكات البرامج، الإيميلات، وغيرها) مشفّرة على جهازك فقط — بدون إنترنت وبدون أي خادم — ولا يمكن الوصول إليها إلا برمز سري تختاره أنت.

A Windows program that keeps your **files and digital accounts** (software subscriptions, emails and more) encrypted on your own PC — no internet, no server — accessible only with a secret PIN you choose.

## ماذا يحفظ؟ — What does it protect?

1. **الملفات / Files** — مستندات، صور، فيديوهات، صوتيات، أي نوع ملف، تظهر بأيقوناتها الأصلية، مع مشغّل فيديو وصوت مدمج.
   Documents, photos, videos, audio — any file type, shown with their original Windows icons, with a built-in video/audio player.
2. **الحسابات الرقمية / Digital accounts** — اشتراكات البرامج والخدمات، حسابات البريد الإلكتروني، التواصل، البنوك، المتاجر: اسم الخدمة، اسم المستخدم، كلمة المرور، والرابط.
   Software and service subscriptions, email, social media, banking and shopping accounts: service, username, password and link.

## التنزيل — Download

من صفحة **[آخر إصدار / Latest release](../../releases/latest)** نزّل أحد الملفين:

| الملف / File | الوصف | Description |
|---|---|---|
| `SecureVault-Setup-<version>.exe` | النسخة الثابتة: مثبّت عادي (قائمة ابدأ + سطح المكتب) | Installed edition: a regular installer |
| `SecureVault_Portable-<version>.zip` | النسخة المحمولة: فك الضغط وشغّل `SecureVault.exe` من أي مكان (فلاش/هارد خارجي) | Portable edition: unzip and run `SecureVault.exe` from anywhere |

**لا يحتاج بايثون ولا أي برنامج آخر ولا إنترنت.** — **No Python, no other software and no internet required.**

> عند أول تشغيل قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً: اضغط "معلومات إضافية" ثم "تشغيل على أي حال".
> On first run Windows SmartScreen may warn because the file isn't digitally signed: click "More info" → "Run anyway".
