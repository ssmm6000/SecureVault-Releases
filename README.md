# المحفظة الآمنة — Secure Vault

برنامج لويندوز يخفي ملفاتك (مستندات، فيديوهات، صور، أي ملف) بعد تشفيرها على جهازك فقط — بدون إنترنت وبدون أي خادم — ولا يمكن الوصول إليها إلا برمز سري تختاره أنت.

A Windows program that hides your files (documents, videos, images — any file) by encrypting them locally on your own PC — no internet, no server — accessible only with a secret PIN you choose.

## التنزيل — Download

من صفحة **[الإصدارات / Releases](../../releases/latest)** نزّل أحد الملفين:

| الملف / File | الوصف | Description |
|---|---|---|
| `SecureVault-Setup-<version>.exe` | النسخة الثابتة: مثبّت عادي (قائمة ابدأ + سطح المكتب) | Installed edition: a regular installer |
| `SecureVault_Portable-<version>.zip` | النسخة المحمولة: فك الضغط وشغّل `SecureVault.exe` من أي مكان (فلاش/هارد خارجي) | Portable edition: unzip and run `SecureVault.exe` from anywhere |

يتطلب وجود Python 3 على الجهاز. — Requires Python 3 on the PC.
